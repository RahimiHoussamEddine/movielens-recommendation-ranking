# Dataset terms and attribution

This project uses the MovieLens 1M ratings dataset from GroupLens Research at
the University of Minnesota. The upstream dataset may be used for research
under its own terms; it is not licensed under this repository's MIT license.
The GroupLens terms prohibit redistribution without separate permission and
prohibit commercial or revenue-bearing use without permission. Review the
upstream [dataset page](https://grouplens.org/datasets/movielens/1m/) and its
linked README before acquiring or using the data.

Raw MovieLens data and the locally generated inference bundle are excluded
from Git. This repository contains source code and aggregate evaluation
results only. Do not redistribute the source dataset or use this project for
commercial or revenue-generating purposes without permission from GroupLens.

Please cite:

> Harper, F. M., & Konstan, J. A. (2015). The MovieLens Datasets: History and
> Context. *ACM Transactions on Interactive Intelligent Systems*, 5(4).
> https://doi.org/10.1145/2827872

Project code is MIT-licensed; the MovieLens data terms are separate and apply
to any local data acquired from GroupLens. The Hugging Face mirror used as a
fallback transport does not grant different rights to the MovieLens files.
